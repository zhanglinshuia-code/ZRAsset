# 包目录与支持范围

[文档首页](../index.md)

| 路径 | 用途 |
| --- | --- |
| Runtime | 核心资源、文件、版本、启动和诊断代码 |
| Editor | 收集、构建、配置和诊断，仅在 Unity Editor 中编译 |
| Editor/SBP | 可选 Scriptable Build Pipeline 后端 |
| Plugins/WebGL | 下载与持久化 JavaScript 桥 |
| Samples~/Core | 入门、加载、下载与启动示例，按需导入 |
| Samples~/各集成 | 第三方桥接示例，按需安装对应 SDK |
| Documentation~ | 使用手册与 API、配置参考 |
| README.md、package.json | 项目入口与 UPM 包信息 |

在 Package Manager 的 Samples 中导入所需示例。核心运行时不要求安装可选集成的第三方 SDK。

平台能力和接入要求见[平台说明](../manual/platforms.md)。
